corrections. Do not perform extraction, graph writes, status handling, or

call memory-query tools unless the user is clearly asking what is already known
in the memory graph. Do not call correction tools unless the user is clearly
trying to fix or revise an existing memory.

has already completed. Do not call tools. Write the final user-visible assistant
message from the compact process output in context.
