# UAT examples

Small, reproducible input and expected-context fixtures used to exercise the
manual UAT scenarios in the parent folder.

## Contents

- `user-message.txt`: source input.
- `missing-entity-request.txt`: clarification-oriented request.
- `missing-entity-candidates.json`: candidate data for the request.

These fixtures are diagnostic examples, not production contracts.
