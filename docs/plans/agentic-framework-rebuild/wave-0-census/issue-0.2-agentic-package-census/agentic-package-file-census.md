# Census the agentic package files

**Status: Complete**

## Objective

Read each listed source file and document its current role, useful behavior or
contract evidence, what should not carry forward, and one proposed treatment.
The assessments below are evidence for rebuild planning, not a decision to
preserve the present code. “Rebuild behavior” means implement the accepted
responsibility anew; it does not mean copy the file.

The shared assessment fields are defined in [census scope](../issue-0.1-scope-and-boundaries/define-census-scope.md).
Production consumers and cross-package dependencies are inventoried in
[Issue 0.3](../issue-0.3-integration-census/README.md); behavioral and test
evidence is indexed in [Issue 0.4](../issue-0.4-contract-and-test-evidence/README.md).
