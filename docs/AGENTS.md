# Documentation instructions

Use [Documentation Conventions](documentation-conventions.md) as the single
source of truth for document structure, indexing, and maintenance. Use
[Technical Principles](requirements/technical/technical-principles.md) for
scope and canonical ownership rules.

Before changing documentation, find the owning page through the relevant
`README.md` index. Update that owner and its index when needed. Prefer links to
the canonical owner over copied rules or duplicated flow descriptions. Keep
indexes accurate and documentation aligned with accepted user requirements.

When a user requirement conflicts with current documentation, state the gap
clearly and follow the user's explicit decision. If the requirement leaves a
material choice unresolved, clarify that choice. Update the canonical owner and
its indexes once the decision is clear; do not silently expand requirements.
