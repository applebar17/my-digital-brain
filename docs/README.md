# Documentation

This folder is the navigational entry point for the project's product,
architecture, AI, and domain documentation. Each subject area owns its detailed
specification in its own folder; this page indexes those sources rather than
repeating their content.

## Start here

- [Product foundation](requirements/product-foundation.md): product vision,
  goals, and non-goals.
- [MVP baseline](mvp/baseline.md): current MVP scope and architectural stance.
- [System architecture](architecture/system-architecture.md): component
  boundaries, external services, storage, and deployment posture.
- [AI engineering](ai-engineering/README.md): AI contracts, runtime, states,
  prompts, context, and provider boundaries.
- [Documentation conventions](documentation-conventions.md): rules for
  maintaining this documentation set.
